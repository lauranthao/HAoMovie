# HAo Movie

HAo Movie — 影视应用，参照映匣（Yingxia, [jo32/tvbox-silicon](https://github.com/jo32/tvbox-silicon)，GPL-3.0）的功能与交互自研，代码全部重写，不复制参照源码。

## 参照与许可

- 参照：映匣 Yingxia — Swift + SwiftUI + AVPlayer，原生 TVBox 播放器（直播 + 点播片库 + 全源搜索）。
- 许可注意：映匣为 GPL-3.0。本仓库只学其功能结构与交互设计，所有实现均为原创；如未来直接引用映匣代码，本仓库须同样以 GPL-3.0 开源。
- 不内置任何片源、不内置账号：订阅、历史、收藏只存本机。

## 第一版范围（0.1.0，骨架）

- 订阅导入：TVBox JSON（URL / 粘贴），多订阅合并、停用、失败冷却 10 分钟；只支持 JSON 源（type 1/4），jar 插件源不支持。
- 片库：继续观看横轨、源站 chips、分类 chips、海报墙（3 列 + 分页加载）。
- 详情：16:9 大图 + 渐变、简介展开、大红播放键、选集数字格、线路分段切换、收藏、断点续播。
- 播放器：AVPlayer，0.5x–4x 倍速、手势（点按显隐、双击 ±10 秒、左滑亮度/右滑音量）、画中画、断点续播、自动连播、跳过片头/片尾（可配）、播放失败不丢历史。
- 全源搜索：并行跑遍各源，结果陆续出现，失败的源可单独重试；搜索历史本机 20 条。
- 直播：M3U / M3U8 分组浏览、频道搜索、收藏（地址由用户在设置里自填）。
- 我的：继续观看、收藏、订阅管理、设置。
- 无启动动画：进应用直接到主界面（chen 2026-11-26 决定）。

## HAo 自己的设计（与映匣不同的地方）

- 页签排布：片库 / 搜索 / 直播 / 我的（四页签，映匣不是这个结构）。
- 首页：继续观看横轨在最上 + 源站 chips + 分类 chips + 海报墙；海报卡片 2:3、圆角 10、标题 13 号半粗。
- 详情：顶部 16:9 大图 + 渐变压暗，标题压在图上；大红播放键在下；选集 5 列数字格。
- 播放器控制层：HAo 自己的黑底渐变控制条 + 红色进度条；跳过片头/片尾按钮直接放在底栏。
- 设计 token：品牌红 #F04438、间距只用 4/8/12/16/20/24 六档、圆角 12/10/8/20。
- 播放规则照映匣的来：断点续播、自动连播、失败不丢历史、倍速范围（chen 2026-11-26：播放规则用他们的，别自己发明）。

## 结构

```
Sources/HAoMovie/
  App/            入口、Tab 栏
  Core/
    Models/       TVBox 订阅/影片/直播/历史模型
    Sources/      TVBox 解析（纯函数）/ 网络客户端 / 订阅 / M3U / 搜索 / 历史
    Player/       AVPlayer 封装、播放状态
    Storage/      本地键值存储、播放偏好
  DesignSystem/   HAo 设计 token
  Features/       片库 / 详情 / 播放器 / 搜索 / 直播 / 我的 / 设置 / 共用视图
  Resources/      Info.plist、Assets（含 AppIcon）
```

## 构建

- Xcode 26+，iOS 17.0+，Swift 6；首次构建需在 Xcode 里选自己的 Team 签名。
- 图标：黑场记板 + 白播放键（chen 2026-11-26 选定），1024 图在 `Sources/HAoMovie/Resources/Assets.xcassets/AppIcon.appiconset/`。
- 本机无 Xcode 时的验证：`swiftc -parse` 全文件 + Linux harness（纯解析函数）。
